# Contexte pour le panel

VisaFlow est un SaaS multi-agences pour opérateurs de visas et de fret en
Tunisie (et clientèle libyenne). Il gère : réception de demandes, suivi de
dossiers de visa, file d'attente de rendez-vous consulaires, cargaisons
Chine-Tunisie-Libye, paiements, messages, un portail client sans compte, et
deux apps mobiles.

## Ce que tu peux regarder
- L'étude de marché complète : `docs/marche/` (acteurs, process, droit,
  fonctionnalités, données). Lis-la, elle est dense et sourcée.
- Le code du front agence : `web/src/pages/` (18 écrans), `web/src/components/`.
- Les apps mobiles : `ios/Sources/`, `android/app/src/main/`.
- Les captures : `rapports/agency-real.png` (espace agence réel),
  `rapports/admin-final.png` (console plateforme), `rapports/ios-accueil.png`,
  `rapports/android-accueil.png`.
